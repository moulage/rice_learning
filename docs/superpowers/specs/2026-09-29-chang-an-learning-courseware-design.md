# 长安幼小衔接学习课件设计

## 背景与目标

本课件面向一名陕西省西安市 6 岁儿童。孩子已有一定数学和识字经验，但没有完成系统学习。产品目标是通过电脑浏览器提供一套可在线访问、知识准确、节奏可控、能持续吸引孩子的幼小衔接课程。

产品不是考试训练系统，也不是超前学科班。它以“长安学习地图 + 创作学习乐园”组织学习，让孩子每天完成短课时任务，点亮西安地点，并把数学、语文、英语知识放进真实生活情境。

## 用户与核心需求

### 目标儿童

- 年龄：6 岁。
- 地区：陕西省西安市。
- 已有能力：有一定数学和识字基础，但没有系统学习。
- 学习设备：电脑浏览器。
- 注意力特点：单次学习适合 10-15 分钟，需要图像、声音、大按钮和即时反馈。
- 动机特点：喜欢可看见的成长、地图探索、星星徽章和创作成果；害怕答错被批评，不喜欢长文字和重复机械练习。

### 核心需求

1. 数学、语文、英语三类学科内容形成完整知识体系。
2. 拼音是语文主线，4 周完成认读、听辨和简单拼读目标。
3. 英语以字母学习优先，4 周完成 A-Z 认读、听辨和首音感知。
4. 数学从已有基础快速校验进入一年级预备内容，不重复低难度学习。
5. 学习过程必须正向、低压力、可恢复，不做惩罚和排名。
6. 家长可以查看进度、掌握点和复习建议。
7. 课件发布到 GitHub 并通过 GitHub Pages 在线访问，非本地机器也能使用。
8. 儿童学习数据保存在本地浏览器，不上传账号、录音或身份信息。

## 学期结构

课程共 16 周，每周 5 次学习，每次 10-15 分钟。默认每天最多学习 2 节主课和 1 节短复习，完成一课后必须手动进入下一课。

| 星期 | 课程类型 | 重点 |
|---|---|---|
| 周一 | 数学加速课 | 数感、运算、图形、时间、人民币、一年级衔接内容 |
| 周二 | 语文拼音课 | 拼音听辨、认读、声调、简单拼读、高频字表达 |
| 周三 | 英语字母课 | A-Z 字母名、大小写、首音、代表词和主题表达 |
| 周四 | 探索创作课 | 把三科知识放入长安城市情境，完成创作卡 |
| 周五 | 复习闯关课 | 复习本周知识点，生成学习证据，点亮长安地点 |

## 知识体系

### 数学

第 1 周先做快速诊断，确认 0-20 数感、10 以内加减、分类比较和图形识别是否稳定。后续课程不重复教已经掌握的内容。

16 周路线：

1. 第 1 周：0-20 数感、10 以内加减、图形分类、比较规律校验。
2. 第 2 周：100 以内数序、整十数、比较大小。
3. 第 3 周：20 以内加法和凑十法探索。
4. 第 4 周：20 以内减法和破十法探索。
5. 第 5 周：加减法应用题，包括购物、分物、排队和求剩余。
6. 第 6 周：规律、分类和简单统计表。
7. 第 7 周：圆形、三角形、正方形、长方形。
8. 第 8 周：球、正方体、长方体、圆柱初步认识。
9. 第 9 周：上下、前后、左右和路线行走。
10. 第 10 周：整点、半点和日程表。
11. 第 11 周：1 元、5 元、10 元人民币和简单购物。
12. 第 12 周：长度、高度、重量比较与简单测量。
13. 第 13 周：100 以内不进位加法。
14. 第 14 周：100 以内不退位减法。
15. 第 15 周：100 以内加减混合应用。
16. 第 16 周：综合项目“长安半日游”，综合使用路线、时间、钱币和加减。

20 以内进位加法和退位减法只要求在教具、图像和生活情境中理解，不要求机械口算熟练。课件不包含乘除法、分数、方程、小数运算和文言文。

### 语文拼音

拼音是语文第一主线，4 周完成基础认读和拼读目标。“掌握”定义为能听辨、认读、选图、跟读和简单拼读，不要求默写或抄写整页拼音。

第 1 周：

- a、o、e、i、u、ü。
- 四声声调。
- b、p、m、f。
- d、t、n、l。

第 2 周：

- g、k、h。
- j、q、x。
- zh、ch、sh、r。
- z、c、s。
- y、w。

第 3 周：

- ai、ei、ui。
- ao、ou、iu。
- ie、üe、er。
- an、en、in、un、ün。

第 4 周：

- ang、eng、ing、ong。
- 两拼音节。
- 三拼音节初步。
- 常见音节认读和声调游戏。
- 拼音综合闯关。

第 5 周开始，拼音进入持续应用：拼读高频字、阅读地点卡、表达长安情境和完成复习任务。语文同时保留 80-120 个高频字、图意表达、生活标识和前书写意识，但优先级后移。

### 英语字母

英语第 1-4 周完成 A-Z 字母优先学习：

1. 第 1 周：A、B、C、D、E、F、G。
2. 第 2 周：H、I、J、K、L、M、N。
3. 第 3 周：O、P、Q、R、S、T。
4. 第 4 周：U、V、W、X、Y、Z 和 A-Z 总复习。

每课流程为字母歌、大小写认读、首音选图、跟读和字母小任务。第 5 周开始进入持续拓展，包括学校、家庭、颜色、数字、动物、食物、身体、天气、文具和交通。常见表达包括 “Hello” “I can see...” “It’s a...” “I like...”。

英语不教语法规则、拼写背诵、翻译式长句和考试化评价。字母名与首音必须分开讲解，避免孩子把英语字母读音和拼音混淆。

### 长安探索与创作

16 周对应 16 个可点亮地点，包括钟楼、鼓楼、城墙、大雁塔、小雁塔、碑林、大唐不夜城、回民街、陕西历史博物馆、西安博物院、地铁站、公园、书店、菜市场、学校门口和运动会。

每个地点绑定一次综合任务，例如用拼音打开钟楼门牌、用数学购买车票、用英语向卡通游客问好、用图形拼出城墙图案、用顺序卡安排博物馆参观。完成地点任务后点亮地图，并获得一张创作卡。

## 学习体验设计

### 首页

首页只保留 4 个入口：

1. 今天学。
2. 长安地图。
3. 我的作品。
4. 给家长。

入口使用大图标、稳定颜色和语音朗读。孩子不需要先理解复杂文字也能找到下一步。

### 课时流程

每节课固定 5 步：

1. 开始：小向导说明今天任务。
2. 学一学：用动画、音频和图形讲解知识点，单次讲解不超过 90 秒。
3. 练一练：完成 3-5 个互动任务。
4. 用一用：把知识放入长安情境。
5. 我学会了：孩子选择或说出学习成果，系统保存学习记录。

### 任务类型

课件包含以下任务类型：

1. 图片选择。
2. 听音选图。
3. 拼音配对。
4. 字母配对。
5. 分类排序。
6. 点数计算。
7. 拨钟表。
8. 人民币付款。
9. 轻量描画。
10. 跟读录音。
11. 路线选择。
12. 创作卡表达。

按钮和可交互区域的最小尺寸为 72px。桌面鼠标、触屏和键盘基础操作都必须可用。

### 反馈规则

答对时反馈具体能力，例如“你已经能认 b、p、m”“你会把 10 分成 6 和 4”“你能听出字母 A 的首音”。

答错时不显示大红叉、不扣星、不惩罚。第一次错误提示线索，第二次错误示范正确思路，第三次允许孩子跟随完成。连续错误会记录为需要复习，并进入简化讲解，不会卡死课程。

### 激励系统

奖励分为三层：

| 奖励 | 获得方式 | 作用 |
|---|---|---|
| 知识星 | 掌握单课知识点 | 显示在课节点上 |
| 地点灯 | 完成一周综合任务 | 点亮长安地图 |
| 创作徽章 | 完成创作卡 | 收进“我的作品” |

课件不使用排行榜、概率抽奖、虚拟商城、倒计时压迫或连续题海。奖励只解锁地图装饰、地点故事、向导服装和创作材料。

## 家长中心

家长入口通过算式确认或长按 3 秒进入，避免儿童误触。

家长可见内容：

1. 三科进度条。
2. 当前周和对应长安地点。
3. 已掌握知识点。
4. 需要复习知识点。
5. 今日和每周学习时长。
6. 创作卡、地点任务和复习证据。
7. 下周建议。

家长可设置：

1. 每日最大主课数量。
2. 单次学习时长上限。
3. 音量和语速。
4. 动画强度。
5. 是否允许进入下一周。
6. 数据导出和恢复。

家长报告不使用分数排名，而是使用能力描述。例如：“孩子能认读 A-G 的字母名和大小写；能稳定认读 a、o、e、i、u、ü；能完成 10 以内购物付款；在提示后能完成 20 以内进位加法。”

## 儿童保护与防疲劳

1. 每节课 10-15 分钟。
2. 默认每天最多 2 节主课加 1 节短复习。
3. 完成一课后返回地图，不自动开始下一课。
4. 每 5 分钟左右出现一次身体活动或远眺提示。
5. 动画不做高频闪烁，音效默认柔和低音量。
6. 长时间无操作自动暂停课程，不继续计时。
7. 重置进度、修改每日上限等敏感操作必须家长确认。
8. 不采集儿童身份信息，不调用摄像头，不展示广告，不做外部链接跳转。
9. 跟读录音只保存在当前浏览器本地数据中，不上传服务器；家长可以在设置中按课节或按日期删除。

## 技术架构

### 技术栈

| 层级 | 方案 |
|---|---|
| 应用框架 | React + TypeScript + Vite |
| 状态管理 | Zustand 或轻量 React Reducer |
| 课程内容 | 结构化 JSON、音频、图片 |
| 学习进度 | IndexedDB |
| 关键摘要 | localStorage |
| 音频 | HTML Audio 或 Web Audio |
| 交互动画 | CSS + Framer Motion |
| 打包 | Vite 静态构建 |
| 在线部署 | GitHub Pages |

课件采用本地优先架构。学习记录保存在当前浏览器 IndexedDB 中，不建立云端账号。家长可以导出 JSON 备份，并导入到同一浏览器恢复进度。

## 内容审核流程

每个知识点和课节必须通过 5 层检查后才能上线：

1. 知识审核：核对拼音发音、字母发音、数学定义和一年级衔接范围。
2. 教学审核：检查学习顺序、难度、语言和适龄表达。
3. 结构校验：JSON Schema 检查字段、答案、资源引用和审核状态。
4. 自动化测试：验证正确答案、提示顺序、进度记录和复习规则。
5. 儿童试学验收：观察目标儿童是否理解、是否挫败、是否能完成课程。

课程内容包包含版本号、知识范围、审核人和发布状态。未通过审核的内容不能出现在课程目录中。

## 测试与验收

### 功能测试

1. 首页、课程、复习、家长中心可正常进入。
2. 每节课 5 个流程完整。
3. 答对、答错、提示、跳过、恢复都能正确记录。
4. 关闭浏览器后能回到原课程和原任务。
5. 完成一周后地图地点正确点亮。
6. 家长确认有效，儿童不能绕过进入设置。
7. 学习数据导出和导入可用。

### 知识准确性测试

1. 所有题目答案唯一或有明确等价答案。
2. 拼音音频、示例字和发音说明逐条核对。
3. 英文字母名与首音不混淆。
4. 数学题表述不产生歧义。
5. 每道题绑定知识点，错题能归因。
6. 不出现超出课程范围的超前内容。

### 儿童可用性测试

1. 孩子能否不看文字理解下一步。
2. 孩子能否在 10 秒内理解当前任务。
3. 是否出现连续挫败。
4. 是否误触家长入口。
5. 单节课是否超过 15 分钟。
6. 休息提示是否有效。

### 兼容性测试

1. Chrome、Edge、Safari、Firefox 最新主版本。
2. Windows 和 macOS 常见桌面分辨率。
3. 1280x720、1440x900、1920x1080。
4. 触屏笔记本。
5. 音频自动播放限制场景。
6. 弱网和刷新恢复场景。

### 验收标准

1. GitHub Pages 提供公开 HTTPS 地址，非本地机器可打开。
2. 首屏加载低于 3 秒。
3. 桌面浏览器交互流畅。
4. 每节课默认 10-15 分钟。
5. 每个上线知识点都有审核通过状态。
6. 每个上线课节都有结构校验和自动化测试通过记录。
7. 目标儿童能独立完成至少 3 节课。
8. 中途关闭后重开不丢进度。
9. 连续使用 30 分钟会被要求休息。

## 发布与交付

源码托管到 GitHub。默认使用 GitHub Pages 发布静态构建产物，部署地址为：

```text
https://<github-owner>.github.io/<github-repo>/
```

实施时通过 GitHub Actions 完成以下流程：

1. 安装依赖。
2. 类型检查。
3. 自动化测试。
4. 课程内容 JSON Schema 校验。
5. 生产构建。
6. 部署到 GitHub Pages。

为让非本机用户无需私有权限访问，默认仓库和 GitHub Pages 站点使用公开模式。如果用户后续要求私有站点访问，则需要改为付费私有 Pages、密码网关或独立托管方案。

实际访问地址由仓库所有者、仓库名和 GitHub Pages 设置生成，并在部署流水线结果中输出。

## 非目标

1. 不做账号注册和云端儿童画像。
2. 不做摄像头采集和人脸识别。
3. 不做广告、外部推荐和社交功能。
4. 不做概率抽奖和虚拟商品消费。
5. 不做排名和同伴比较。
6. 不做整页机械抄写。
7. 首版不做多儿童档案，只保留一个本地儿童学习档案。

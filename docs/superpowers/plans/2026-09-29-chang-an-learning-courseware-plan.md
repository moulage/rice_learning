# 长安幼小衔接学习课件实施计划

## 目标

实现一个本地优先的 React + TypeScript 浏览器课件，覆盖设计文档中的 16 周学习地图、拼音优先、字母优先、数学加速、复习闯关、创作卡、家长中心和 GitHub Pages 部署。

## 角色分工

| 角色 | 实施责任 |
|---|---|
| 教育体系专家 | 校准知识点顺序、年级衔接范围和适龄语言 |
| 幼小衔接教师 | 设计课程目标、练习结构、提示和复习规则 |
| 开发者 | 实现课程引擎、进度模型、恢复机制和类型安全 |
| 设计师 | 实现长安地图、大按钮界面、色彩和低刺激反馈 |
| 前端开发 | 实现 React 组件、状态管理、任务渲染和家长中心 |
| 测试者 | 建立内容校验、单元测试、交互测试和发布检查 |

## 里程碑

### M0：项目基座

- 初始化 Vite + React + TypeScript。
- 建立 `src/domain`、`src/content`、`src/components`、`src/hooks`、`src/tests` 目录。
- 配置 TypeScript、Vite、测试脚本和 GitHub Actions。
- 建立路径别名、全局样式和响应式外壳。

验收：`npm run build`、`npm run test`、`npm run lint` 全部通过。

### M1：课程模型与进度引擎

实现核心类型：

```text
KnowledgePoint
LessonSegment
LessonTask
Lesson
CurriculumWeek
LearningEvent
MasteryRecord
AppProgress
ParentSettings
```

实现能力：

- 按星期返回今日课程。
- 记录每题尝试次数、用时、提示后结果。
- 计算知识点掌握度和下一复习时间。
- 刷新或关闭浏览器后恢复当前课节。
- 默认每天最多 2 节主课和 1 节复习。
- 保存家长设置和本地学习档案。

验收：进度写入、恢复、掌握度和每日上限有单元测试覆盖。

### M2：16 周课程内容

在 `src/content` 建立结构化课程数据：

1. 数学 16 周：从快速校验到 100 以内加减应用。
2. 拼音 4 周集中课和第 5-16 周应用课。
3. 英语 A-Z 4 周集中课和第 5-16 周主题拓展课。
4. 探索创作课 16 周，对应长安地点。
5. 复习闯关课 16 周，综合本周三科知识点。

每课必须包含：

- 唯一 ID。
- 星期和周次。
- 知识点编号。
- 学习目标。
- 5 段课时流程。
- 互动任务和答案。
- 错误提示。
- 审核状态。

验收：内容校验器证明 80 节课完整、无重复 ID、资源引用有效、审核状态为 approved。

### M3：儿童学习界面

实现页面：

1. 儿童首页。
2. 长安地图。
3. 课程播放器。
4. 我的作品。
5. 复习中心。
6. 家长中心。
7. 设置中心。

交互要求：

- 主要按钮最小 72px。
- 首页入口有图标、颜色和语音朗读。
- 每屏只呈现一个主任务。
- 错误反馈不使用大红叉或惩罚。
- 动画克制，避免高频闪烁。
- 每课结束返回地图，不自动开始下一课。

验收：目标课节可从首页连续完成，中途刷新后不丢进度。

### M4：任务组件

首版实现以下可运行组件：

1. `ChoiceTask`。
2. `AudioChoiceTask`。
3. `MatchTask`。
4. `SortingTask`。
5. `CountingTask`。
6. `ClockTask`。
7. `MoneyTask`。
8. `TracingTask`。
9. `RecordingTask`。
10. `CreationCardTask`。

每个组件统一接入任务上下文、作答事件、提示状态、重试状态和完成回调。

验收：每种任务类型至少有一条自动化交互测试。

### M5：家长中心与防疲劳

实现：

- 三科进度条。
- 已掌握/待复习知识点。
- 学习时长和课节数。
- 每周创作卡与地点任务证据。
- 每日上限、音量、语速、动画强度。
- 学习数据导出/导入。
- 录音删除。
- 家长确认入口。

验收：家长设置变更即时生效，儿童无法绕过确认进入设置。

### M6：内容审核与自动化校验

建立内容检查：

1. 课程 ID 唯一。
2. 16 周 × 5 课完整。
3. 每个任务绑定知识点。
4. 答案唯一或等价答案明确。
5. 每个知识点有定义、示例、错误点和评估方式。
6. 审核 status 为 `approved`。
7. 拼音、英语、数学分别有专家审核字段。

验收：`npm run validate:content` 通过，CI 阻断未审核内容。

### M7：测试与浏览器验收

自动化：

1. 课程模型单元测试。
2. 进度持久化测试。
3. 内容完整性测试。
4. 关键组件渲染测试。
5. 任务交互测试。
6. 构建类型检查。

人工：

1. Chrome、Edge、Safari、Firefox 最新版。
2. 1280x720、1440x900、1920x1080。
3. 刷新恢复。
4. 音频限制场景。
5. 连续学习上限。
6. 家长确认。

### M8：GitHub 与 GitHub Pages

1. 创建或绑定公开 GitHub 仓库。
2. 推送 `main` 分支。
3. 添加 GitHub Actions 工作流。
4. CI 执行类型检查、测试、内容校验和生产构建。
5. 构建产物部署到 GitHub Pages。
6. 在仓库设置开启 Pages。
7. 用外部网络访问最终 HTTPS 地址。

最终地址格式：

```text
https://<github-owner>.github.io/<github-repo>/
```

## 执行顺序

1. 创建 M0 项目基座。
2. 实现 M1 课程模型和进度引擎。
3. 建立 M2 内容生成与校验。
4. 实现 M3/M4 儿童界面和任务组件。
5. 完成 M5 家长中心和设置。
6. 执行 M6/M7 校验与测试。
7. 执行 M8 GitHub Pages 发布。
8. 用线上地址做最终冒烟验收。

## 完成定义

- 80 节课结构完整并可学习。
- 三科知识体系有编号和审核状态。
- 学习进度可恢复。
- 家长中心可查看进度和复习建议。
- 儿童防疲劳规则生效。
- GitHub Actions 通过。
- GitHub Pages 提供公开 HTTPS 地址。
- 非本机浏览器可以完成至少一节完整课程。
